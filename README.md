# Aura Studio — Web Demo

Sitio web demostrativo para un estudio de estética y cuidado de la piel, desarrollado por **Vidrieras Web**.

### Características
- Diseño responsive para celulares, tablets y escritorio.
- Catálogo interactivo de tratamientos con filtros por categoría.
- Galería de imágenes ampliable.
- Animaciones y transiciones al desplazarse.
- Preguntas frecuentes interactivas.
- Accesos preparados para consultas por WhatsApp.
- Configuración centralizada para personalizar los datos del negocio.

### Tecnologías
HTML5, CSS3 y JavaScript.

### Importante
Este proyecto es una demostración de diseño web. Los precios, tratamientos y datos comerciales son ilustrativos. Los canales de contacto requieren configuración antes de utilizarse en un negocio real.
